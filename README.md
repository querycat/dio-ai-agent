# Agente Financeiro Inteligente com IA Generativa

## Contexto

Projeto final do **Bootcamp GenAI, Dados & Cyber, do Bradesco**. O objetivo é prototipar um agente ia do setor financeiro que vai:
- Antecipar necessidades ao invés de apenas responder perguntas
- Personalizar sugestões com base no contexto de cada cliente
- Cocriar soluções financeiras de forma consultiva
- Garantir segurança e confiabilidade nas respostas (anti-alucinação)

Para mais detalhes sobre as etapas deste projeto, leia o [planejamento.md](https://github.com/querycat/dio-ai-agent/blob/main/docs/00-planejamento.md)
